# ScaleOps social media images

Public image hosting for scheduled social posts. GoHighLevel Social Planner
pulls each image from its raw GitHub link at publish time.

- Layout: `<client>/<YYYY-MM>/<YYYY-MM-DD>.png`
- Images only. No captions, client files, IDs or keys ever go in this repo.
- Everything here is public. Only add images that are ready to be posted.
