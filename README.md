# Image hosting

Public images, served by their raw links.

- Layout: `<folder-id>/<YYYY-MM>/<YYYY-MM-DD>.jpg`
- Folder ids are random 16-character hex strings. Never name a folder, file or
  commit after a client or anything that identifies one.
- Images only. No captions, client files, IDs or keys ever go in this repo.
- Everything here is public. Only add images that are ready to be posted.
